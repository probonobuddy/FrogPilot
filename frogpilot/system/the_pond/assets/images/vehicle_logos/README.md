# Vehicle Logo Assets

These logo files identify the detected vehicle make in The Pond's parked Home view.

Most SVG files are vendored from Simple Icons npm package version 16.22.0.

Source: https://simpleicons.org/

The Simple Icons package license and disclaimer are included in this directory as:

- `SIMPLE_ICONS_LICENSE.md`
- `SIMPLE_ICONS_DISCLAIMER.md`

Additional logo files that are not available in Simple Icons are documented in:

- `ADDITIONAL_LOGO_SOURCES.md`
- `AVTO_DEV_VEHICLE_LOGOTYPES_LICENSE.md`

All marks remain trademarks of their respective owners and are used only for vehicle make identification.
